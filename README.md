# MistWeftStudio 拾雾工作室

> 以文字记述世界，以科技留影未来

一个由几名高中生组成的创意工作室，主营游戏制作、微电影拍摄、文学类创作（小说）、短视频创作。

## 官网

本仓库包含拾雾工作室的官方网站代码。

## 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite 6
- **CSS框架**: TailwindCSS 3
- **图标库**: Lucide React

## 功能特点

- 🌟 **星光闪烁背景动效**
- 📱 **响应式设计**
- 🎨 **玻璃拟态UI风格**
- 📋 **单页面锚点导航**
- 📇 **侧边目录菜单**

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产版本
npm run preview
```

## 项目结构

```
src/
├── components/          # React组件
│   ├── Header.tsx       # 导航栏
│   ├── Hero.tsx         # 首页Hero区域
│   ├── About.tsx        # 关于我们
│   ├── Services.tsx     # 服务项目
│   ├── Projects.tsx     # 项目案例
│   ├── Contact.tsx      # 联系方式
│   └── Footer.tsx       # 页脚
├── pages/               # 页面组件
├── App.tsx              # 应用入口
├── main.tsx             # React挂载
└── index.css            # 全局样式
```
